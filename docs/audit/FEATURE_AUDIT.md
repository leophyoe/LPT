## 1. Feature Status Legend

* **IMPLEMENTED:** Feature is implemented, connected end-to-end, and verified by passing automated tests.
* **PARTIALLY IMPLEMENTED:** Feature has working components, but lacks full workflow integration, specific output formats, or full error recovery.
* **NOT IMPLEMENTED:** Architecture planned in roadmap, but no active implementation code exists in codebase.
* **BROKEN:** Implementation exists but fails runtime execution or contains critical defects.
* **UNVERIFIED:** Code exists but lacks automated unit/integration test coverage or live test fixtures.
* **BLOCKED:** Implementation depends on missing external tools, hardware, or third-party API dependencies.
